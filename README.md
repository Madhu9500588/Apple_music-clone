•Apple Music Clone 🎵

My first frontend project — a static Apple Music-inspired music player website built using HTML, CSS, and JavaScript.

•Features

- 🎵 Music player with play/pause, previous and next controls
- 🔊 Volume control
- ⏱️ Clickable song progress bar
- ❤️ Liked Songs using localStorage
- 🎶 Create and manage playlists
- 🔍 Search songs and artists
- 👤 Custom user name
- 📱 Responsive design for desktop and mobile
- 💿 Custom album covers

•Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub Pages

•About the Project

This is my first frontend project. I built it as a learning project to understand how HTML, CSS, and JavaScript work together to create an interactive website.

I used AI tools extensively during development to help me understand concepts, debug code, design features, and implement functionality. I also modified and experimented with the code while building the project.

•Note

This project is an Apple Music-inspired learning project and is not affiliated with Apple.

Built while learning frontend development 🚀
